> 不是 Photoshop，是 PhotoSelect！给你照片做「断舍离」的小工具。

拍了 800 张连拍，最后只想要 10 张？PhotoSelect 把几乎一样的照片自动归成一组，你用大图对比，每组留下最好的一两张，其余一键移走。整个过程一张照片都不会真删，随时能反悔。

## ✨ 它能帮你做什么

- **大图对比选片**：黑底深色界面，照片最大化铺满屏幕，选片只看照片，没有花哨的按钮
- **点一下就是选择**：点击照片切换保留 ✓ / 删除 ✗；键盘也行：←→ 切组、回车确认
- **连拍救星（严格去重）**：几百张连拍自动归成一组，同组只挑最好的那几张
- **人像神器（同主体筛选）**：离线人脸识别，把**同一个场景里同一个人的照片**归到一组（人脸 + 背景双重判断），换人自动拆开
- **废片侦探（模糊识别）**：对焦失败、手抖的糊片自动挑出来，推荐保留清晰的那张
- **JPG + RAW 一起管**：尼康 NEF、佳能 CR2/CR3、索尼 ARW、富士 RAF……RAW 和它的 JPG 成对移动，不会拆散
- **完全离线**：照片不出你的电脑，人脸识别也在本地跑；无广告、无上传

## 🚀 30 秒上手

1. 双击 `PhotoSelect.exe`（免安装）
2. 点「选择文件夹」，选中要整理的照片目录
3. 选文件类型（全部 / 仅 JPG / 仅 RAW）和分析模式（连拍选「严格去重」，人像选「同主体筛选」）；要顺便挑出糊片，就勾上「模糊识别」
4. 点「开始分析」，在「分组总览」里检查分组，想调整就拖一拖
5. 大图选图：点照片 = 保留 ✓，点「确认本组」自动跳下一组；全部确认完点「导出」

被淘汰的照片不会真删，会移进原文件夹里的 `待删除` 文件夹，确认没问题后手动清空就行。

## ✅ 什么时候用它

- **活动、旅行、连拍选片**：几百张挑几张最好的
- **人像选片**：同一个场景里同一个人的 N 张里，选表情、构图最好的
- **照片去重**：场景重复、复制过、下载重复的
- **支持格式**：JPG、主流 RAW（NEF / CR2 / CR3 / ARW / DNG / RAF / RW2 / ORF / PEF / SRW / X3F / ERF）、iPhone 的 HEIC / HEIF

## ⚠️ 注意

- **只支持 Windows**
- **模糊识别有边界**：极轻微的柔焦和真正的对焦失败，算法不总能分清。想要柔和的氛围感，直接点保留就行，你说了算
- **极端构图不自动归组**：特写大脸和远景小人，可能分不到一组。在「分组总览」里手动拖到一起就行，几秒钟的事
- **大文件夹首次分析慢**：几千张需要几分钟，正常现象（约 300 张 ≈ 10 秒）
- **杀毒软件误报**：个别杀软会对打包工具误报，加白名单即可。本软件完全离线、不联网

## 💬 常见疑问

- **被删的照片还能找回来吗？** 能。「待删除」文件夹里的照片只是被移走，不是删除；也可以在软件里点「撤销本组确认」自动恢复
- **支持哪些相机和格式？** 尼康、佳能、索尼、富士、松下、适马等主流 RAW（NEF / CR2 / CR3 / ARW / DNG / RAF / RW2 / ORF / PEF / SRW / X3F / ERF），JPG，以及 iPhone 的 HEIC / HEIF
- **我的照片会被上传吗？** 不会。软件完全离线运行，人脸识别也在本机处理，照片不出你的电脑
