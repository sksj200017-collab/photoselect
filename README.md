> 不是 Photoshop，是 PhotoSelect！——给你照片做「断舍离」的小工具。

拍了 800 张连拍，最后只想要 10 张？PhotoSelect 把「几乎一样的照片」自动归成一组，你用大图对比，每组留下最好的一两张，其余一键移走。整个过程**一张照片都不会真删**，随时能反悔。

## ✨ 为什么摄影师会喜欢它

- **Lightroom 式大图对比**：黑底深色界面，照片最大化铺满屏幕——主角是照片，不是按钮
- **点一下就是选择**：点击照片切换 保留 ✓ / 删除 ✗；键盘流也行：←→ 切组、回车确认
- **连拍救星（严格去重）**：几百张连拍自动归组，同组只挑最好的那几张
- **人像神器（同主体筛选）**：离线 AI 人脸识别，同一个人的所有照片自动归到一组，换人自动拆开——不用一张张翻
- **废片侦探（模糊识别）**：对焦失败、手抖的糊片自动挑出来，推荐保留清晰的那张
- **后拍优先**：同一组自动推荐保留拍摄时间最新的那张（连拍的后面几张，表情通常最好）
- **JPG + RAW 一起管**：尼康 NEF、佳能 CR2/CR3、索尼 ARW、富士 RAF……RAW 和它的 JPG 成对移动，不会拆散
- **完全离线**：照片不出你的电脑，人脸识别也在本地跑；无广告、无上传

## 🚀 30 秒上手

1. 双击 `PhotoSelect.exe`——免安装，双击即用
2. 点「选择文件夹」，选中要整理的照片目录
3. 选文件类型（全部 / 仅 JPG / 仅 RAW）和分析模式（连拍选「严格去重」，人像选「同主体筛选」），点「开始分析」
4. 在「分组总览」里检查分组——想调整就拖一拖、加一加
5. 进入大图选图：**点照片 = 保留 ✓**，点「确认本组」自动跳下一组；全部确认完点「导出」

被淘汰的照片不会真删，而是移进原文件夹里的 `_待删除` 文件夹——确认没问题后手动清空它就行。

## ✅ 什么时候用它

- **活动 / 旅行 / 连拍选片**：几百张挑几张最好的
- **人像选片**：同一个人的 N 张里选表情、构图最好的
- **照片去重**：场景重复、复制过、下载重复的
- **支持格式**：JPG、主流 RAW（NEF / CR2 / CR3 / ARW / DNG / RAF / RW2 / ORF / PEF / SRW / X3F / ERF）、iPhone 的 HEIC / HEIF

## ⚠️ 什么时候别太指望它

- **只支持 Windows**
- **模糊识别有边界**：极轻微的柔焦（"不够锐"）和真正的对焦失败，算法不总能分清；如果你本来就想保留那种柔和的氛围感，直接点保留就行
- **极端构图**：特写大脸 vs 远景小人，可能不会被自动归组——在「分组总览」里手动拖一下就行
- **几千张的大文件夹**：首次分析需要几分钟，属正常现象（约 300 张 ≈ 10 秒）
- **杀毒软件误报**：个别杀软会对打包工具误报，加白名单即可——本软件完全离线、不联网
